README structure:
1. One-line description + badges placeholder.
2. Why it exists (problem statement, 2-3 sentences).
3. Quickstart: install → minimal working example that ACTUALLY runs (verify commands exist in the repo first).
4. Configuration reference table.
5. Architecture overview only if non-obvious.
Rules: no marketing fluff, no emoji spam, code blocks with language tags, verify every command you include by reading the repo.
